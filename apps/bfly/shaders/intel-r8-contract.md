# Intel wing cache and presentation contract

The coupled Vulkan fixture ran the stock bfly shaders on Mesa 26.0.8 and the Intel RPL-S iGPU (`8086:a780`). It rendered all eight layers of one linear R8 texture, generated its mip chain and sampled that same texture into a 3072×1728 RGBA8 framebuffer. The linear and tiled textures gave identical readback at 0 and 1/30 seconds. Both frames matched the OpenGL preview within one 8-bit unit per RGB channel. The fixture counts 34,591 wing pixels at time zero and 70,517 red-channel changes at the next frame.

An offline run against Mesa's Intel DRM stub for ADL-S (`8086:4680`, revision `0c`) produced the same decoded array, mip, sampler, topology, viewport and cache transition fields throughout the sequence. The offline run records the driver's packet choices only. The real iGPU execution and pixel readback above were on RPL-S.

## Cache allocation and views

Allocate eight layers of 1028×1028 `R8_UNORM`, with 11 mip levels and no auxiliary surface. The observed linear layout uses a 1,040-byte row, a 1,548-row layer and a 1,609,920-byte layer stride. Reserve 12,879,360 bytes before rounding to the native mapping granularity. The Gen12 array QPitch encodes four-row units, so it is 387. The hardware surface uses horizontal alignment 16 and vertical alignment 4.

Mips 0 and 1 pack down the left column. Mip 2 starts beside mip 1 at `(528, 1028)`, with 528 equal to mip 1's width rounded up to 16. Each following mip starts below its predecessor, whose height is rounded up to 4. The layer height covers both columns. Every offset in the table is relative to its layer base.

| 1 | 514 | 0 | 1028 | 1,069,120 |
| 2 | 257 | 528 | 1028 | 1,069,648 |
| 3 | 128 | 528 | 1288 | 1,340,048 |
| 4 | 64 | 528 | 1416 | 1,473,168 |

An individual render view is 2D with its array bit clear, zero depth and zero view extent, and `Minimum Array Element` set to the selected layer. Its address is the shared base of the entire cache. The display sample view uses the same address with array enabled, depth 7 (eight layers), minimum array element 0, and mip count 10 (eleven levels). Its pixel swizzle is R, zero, zero, one. The capture used these DWORDs before the surface address.

| View | DW0 | DW1 | DW2 | DW3 | DW4 | DW5 | DW6 | DW7 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Layer write | `2501c000` | `e0000183` | `04030403` | `0000040f` | `layer << 18` | `00000b00` | `00000000` | `09770000` |
| Array sample | `3501c000` | `e0000183` | `04030403` | `00e0040f` | `00000000` | `00000b0a` | `00000000` | `08010000` |

DW1 includes the captured Mesa cache policy. The native renderer supplies its own cache policy and GPU address. For a native allocation, keep one resident Render0 mapping for the whole cache. The kernel can reuse the exact retirement and quarantine pattern in `src/intel/render/coverage_mask.rs`.

## Draws and transitions

- Clear each layer to zero. Each bake draw submits 20 sequential vertices, a single instance starting at zero, and `PATCHLIST_4` topology (`0x23`). A vertex contains two control-point floats and one straight-edge float, with a 12-byte stride. `3DSTATE_TE` is isoline, line output, integer partitioning, reversed patch header and max factors 63/64. For `N = 8 << layer`, use an `N + 4` square viewport and the bake projection in `tools/render_bfly.py`. Three cubics tessellate at N segments each and the two straight closures use one segment each. The layers had 29, 61, 121, 247, 502, 1003, 2014 and 4052 nonzero pixels in order.
- Filter each mip from its predecessor on the GPU after all base-layer writes. The fixture used ten linear blits across all eight layers, with a write-to-read transition between levels. The source coordinate for a destination texel center is `(dest_texel + 0.5) * source_edge / dest_edge - 0.5`. This includes the 257-to-128 step. The sampler transition after mip generation flushes preceding writes and invalidates the texture cache.
- Present with four sequential vertices and 24 instances starting at zero, with `TRISTRIP` topology (`0x05`) and vertex and instance IDs generated by the GPU. The first eight strips draw the panels, and the other 16 strips draw two triangles per wing. The fragment shader samples the array at Intel binding-table index 2 and sampler index 0. Use normalized coordinates, linear minification and magnification, linear mip filtering, edge clamp in U/V/W, zero LOD bias, and LOD range 0–10. The sampled sampler-state words in the capture were `50324000 000a0001 <border-color pointer> 0007e092`. The display blend is premultiplied `ONE, ONE_MINUS_SRC_ALPHA`.
- Both passes consume 160 bytes of std140 uniforms. The display framebuffer tuple is width, height, time, nearest camera distance. Time is at byte 152 and nearest camera distance is 6. For comparison with the OpenGL preview, the fixture used positive Vulkan viewport height and reversed readback rows. Account for this Y convention when selecting native presentation coordinates, including the pixel position read by the fragment shader.

## Local capture

The scratch fixture, decoded Intel commands, and two-frame readbacks are under the ignored `target/coupled-vulkan-r8/` directory, with the ADL-S commands in `adls-packets/stderr`. Mesa's decoder stopped after the first chained command buffer, so the capture splits the bake layers, mip steps, and draws across submits while keeping one image. The same fixture also passed with a single Vulkan submit.

With the scratch fixture and the stock Vulkan shader captures available in this workspace, run from `apps/bfly`:

```sh
fixture="$PWD/target/coupled-vulkan-r8"
stock="$PWD/../../../PotatoStamps/target/wings-intel-capture"
TMPDIR="$fixture" cc -D_GNU_SOURCE -std=c17 -O2 -I../../../tools/vulkan-headers/include \
  "$fixture/record.c" -l:libvulkan.so.1 -o "$fixture/record"
VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/intel_icd.json INTEL_DEBUG=bat BFLY_SPLIT_TAPE=1 \
  "$fixture/record" linear-mips \
  "$stock/cache-pass/vert.spv" "$stock/cache-pass/frag.spv" \
  "$stock/cache-pass/tesc.spv" "$stock/cache-pass/tese.spv" \
  "$stock/closer-display/vert.spv" "$stock/closer-display/frag.spv" \
  > "$fixture/linear-mips.stdout" 2> "$fixture/linear-mips.stderr"
python3 tools/render_bfly.py --frames 2 --output "$fixture/opengl.png"
```
