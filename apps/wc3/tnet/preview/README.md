# Interface previews

These are screenshots of the actual bundled HTML/CSS/JavaScript, rendered in
Chromium using explicitly simulated in-memory API responses. No real Warcraft
server or player session is shown. The visible warning identifies the fixture.
Desktop viewport: 1440 pixels wide. Mobile viewport: 390 pixels wide.

They demonstrate the interface only, not successful installation or an actual
PvPGN login. See TEST-REPORT.md for exactly what was and was not tested.
