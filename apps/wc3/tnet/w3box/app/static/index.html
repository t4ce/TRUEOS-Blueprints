HOW THIS WORKS

A lobby, not a game host.

PvPGN supplies private logins, chat and game listings. A player's Warcraft client still hosts each custom match.

Connect your Windows PC

01

Use your existing RoC 1.21b installation

The realm accepts Windows Reign of Chaos, not The Frozen Throne or Reforged.

02

Supply a compatible legacy loader

Loader not bundled. The modern w3lh/w3l project explicitly excludes versions below 1.22a. Its documentation points older clients to ACiD loader v1.2; no compatible binary was verified for this bundle.

Do not run an unknown executable or disable antivirus to make it run. A gateway change alone is not enough.

03

Add this realm, then launch through your loader

The helper backs up the Windows gateway setting before adding this address. Run it as your normal Windows user, with Warcraft closed.

Get Windows gateway helper

Select your private gateway in the game and create a new account there. Panel and game accounts are separate.
