    THE GUARANTEES

    Make misuse boring

    Helpers produce valid transactions by construction. The boundary validates anyway.

    01

    Order is explicit

    Every delta declares its base and next epoch. Gaps, duplicates, and time travel cannot silently mutate the scene.

    next = accepted + 1
    02

    Ownership is singular

    Handles name an owner, generation, and type. Stale or cross-device handles fail before execution.

    Texture<Gpu0, Gen88>
    03

    Commit is atomic

    Resources, scene operations, damage, and presentation enter as one validated transaction—or not at all.

    validate → stage → publish
    04

    Release follows use

    Destruction is a request. Actual reclamation waits for the last referencing fence to complete.

    retire_after(fence)
    05

    Damage is a promise

    Declared damage must contain computed change. Debug builds reject; production safely promotes to full damage.

    computed ⊆ declared
    06

    Recovery is ordinary

    A rejected delta returns a reason and expected epoch. CPU sends a snapshot; the GPU never guesses.

    NeedSnapshot { expected }

    SHARED LANGUAGE

    The transaction is the truth.

    No callbacks that mutate hidden graphics state. No implicit resource lifetime. No best-effort ordering.

    FrameTx {
  base:  Epoch(1042),
  next:  Epoch(1043),
  reads: [atlas@88],
  ops:   [UpdatePrimitive(card),
          SetScrollOffset(main, 240)],
  damage: Region([48, 96, 320, 180]),
